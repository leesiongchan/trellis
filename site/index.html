Read the setup guide ↗
What do I need to run it?+

A server or local machine with Docker Compose, or the Node and Rust development toolchains. Live research uses your OpenAI and Tavily API keys; provider usage may incur charges. The repository has the setup instructions.

Where does my knowledge live?+

Your saved explorations and answers live in a database on your server, behind the app’s private access link. Live research sends questions to your configured research providers.

Is this page the app?+

This is a small introduction, with prewritten examples you can explore. The full Trellis workspace runs on your own server and researches the questions you bring to it.
